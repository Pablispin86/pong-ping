# 🏓 Pong Ping — Juego clásico en Python

## Descripción

Pong Ping es una recreación del clásico videojuego Pong de Atari, desarrollada en Python utilizando la biblioteca Pygame.

Este proyecto fue realizado durante mis primeros pasos en el aprendizaje de programación, con el objetivo de practicar lógica, movimiento de objetos, eventos del teclado y detección de colisiones.

## Características

- Juego local para dos jugadores.
- Movimiento independiente de las paletas.
- Pelota con rebotes en paredes y paletas.
- Reinicio de la posición de la pelota cuando sale por los laterales.
- Fondo gráfico personalizado.
- Efectos de sonido.
- Ventana de juego de 800 × 600 píxeles.

## Controles

| Jugador | Subir | Bajar |
|---|---|---|
| Jugador 1 | W | S |
| Jugador 2 | Flecha arriba | Flecha abajo |

## Tecnologías utilizadas

- Python
- Pygame
- Manejo de eventos de teclado
- Detección de colisiones
- Programación de videojuegos 2D

## Cómo ejecutarlo

1. Tener Python instalado.
2. Instalar Pygame:

   `python -m pip install pygame`

3. Descargar los archivos del repositorio y mantener los recursos gráficos y de sonido junto al archivo principal.
4. Ejecutar:

   `python pong.py`

## Archivos principales

- `pong.py`: lógica del videojuego.
- `cancha12.png`: imagen de fondo.
- `golpe1.mp3` y `golpe2.mp3`: efectos de sonido.
- `player1.webp`: recurso gráfico incluido en el proyecto.
